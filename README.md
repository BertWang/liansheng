# 連晟旅行社網站專案

## 專案概述

本專案為 **連晟旅行社** 官方網站前端雛形，網站定位為：

> **台南文化旅行入口，而不是一般制式旅行社網站。**

網站以「台南老屋場域、府城文化、在地導覽、客製旅行」為核心，透過雜誌感排版、米白紙感背景、深綠品牌色、宋體標題與大留白設計，建立連晟旅行社的文化品牌形象。

---

## 品牌定位

### 核心主張

**從台南老屋出發，走進真正的府城風景。**

連晟旅行社不只是安排行程，而是帶旅人走入台南的建築、巷弄、歷史、信仰、美食與在地人的日常。

### 網站目標

- 建立連晟旅行社的品牌質感
- 強化「台南在地文化旅行」定位
- 展現老屋場域與府城文化特色
- 提供台南路線、客製行程與聯絡預約入口
- 作為後續正式網站開發的前端基礎

## 頁面說明

### 1. 首頁 `index.html`

首頁負責建立品牌第一印象，主軸為：

**台南文化旅行入口。**

主要區塊：

- Header / 主選單
- Hero 主視覺
- 品牌定位文案
- 服務特色區
- CTA 諮詢區
- Footer 公司資訊

---

### 2. 台南路線 `routes.html`

展示連晟可規劃的台南深度旅遊主題。

路線分類：

- 府城老屋散策
- 巷弄文化走讀
- 廟宇信仰巡禮
- 台南美食慢旅
- 安平歷史小旅行
- 客製府城路線

---

### 3. 行程詳細頁 `route-old-house.html`

目前以「府城老屋散策」作為詳細頁範本。

頁面用途：

- 展示單一行程內容
- 說明行程亮點
- 提供預約與諮詢入口
- 作為後續其他行程頁的模板

---

### 4. 場域故事 `space-story.html`

此頁為品牌差異化重點。

核心概念：

**老屋不是背景，而是旅程的第一個入口。**

內容方向：

- 連晟老屋場域
- 天井、紅磚、木窗、老物件
- 老屋欣力與文化保存
- 台南中西區民權路街區記憶

---

### 5. 客製行程 `custom-trip.html`

提供客製旅遊說明與需求表單。

適合對象：

- 企業旅遊
- 學校參訪

- 銀髮友善旅遊
- 外地朋友台南深度遊

- HTML5

目前不需要安裝套件，可直接用瀏覽器開啟。

---

## 本機預覽方式

### 方式一：直接開啟

直接開啟：

```txt
index.html
```

### 方式二：使用 VS Code Live Server

1. 使用 VS Code 開啟 `liansheng_site` 資料夾
2. 安裝 Live Server 外掛
3. 對 `index.html` 按右鍵
4. 選擇 `Open with Live Server`

### 方式三：使用 Python 本機伺服器

在專案資料夾中執行：

```bash
python -m http.server 8000
```

然後開啟：

```txt
http://localhost:8000
```
